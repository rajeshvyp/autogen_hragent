AutoGen HR Assistant Agent

A beginner friendly AI assistant built using Microsoft's AutoGen framework and OpenAI.

Project Overview:
This project uses an AssistantAgent to generate a five-line job description for a Junior Python Developer.

Key Concepts:
- AssistantAgent
- OpenAIChatCompletionClient
- System messages and task prompts
- Asynchronous execution using asyncio
- Streaming responses with Console

Learned how to create an AutoGen agent, connect it to an OpenAI model, execute a task, and display the AI generated response.
